# Comandos básicos de git

## Conocer el estado de mi work directory

`git status`

# agregar archivos o directorios a git
`git add`

`git add nombre_directorio` directorio

`git add nombre_archivo` un archivo

`git add nombre_archivo otro_archivo` varios archivo

`git add -a` todo

`git add .` todo

## Confirmar los cambios

`git commit -m "mensaje descriptivo"`

## Conocer el historial del proyecto

`git log`
